# samarthpaliwal.github.io

Source for my portfolio at [samarthpaliwal.github.io](https://samarthpaliwal.github.io): education,
experience, project case studies and contact.

Static HTML and CSS with a small amount of JavaScript (GSAP for scroll animation), served by GitHub Pages
from the `main` branch. No build step: open `index.html` in a browser, or run
`python3 -m http.server` in this folder.

| File | Page |
|---|---|
| `index.html` | Home |
| `projects.html` | Project case studies |
| `experience.html`, `education.html` | Experience and education |
| `connect.html` | Contact and meeting times |
| `site.css`, `styles.css`, `site.js` | Shared styles and behaviour |
